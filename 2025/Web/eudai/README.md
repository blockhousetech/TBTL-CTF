# EUD(A)I

## Description

I've been working on an
[EUDI](https://digital-strategy.ec.europa.eu/en/policies/eudi-regulation)
showcase which I'll present at the next big conference.  🇪🇺

Basically, I've taken the [Architecture and Reference
Framework](https://eu-digital-identity-wallet.github.io/eudi-doc-architecture-and-reference-framework/1.1.0/arf/)
and fed it to a popular LLM 🙈

I repeatedly asked the LLM to summarize the standards until it spit out
something I could finally understand.  The LLM's implementation should be
secure... If you want to convince me it isn't, find Bill Roscoe's flag! 🚩

***Note:*** To prevent you from guessing the flag, you'll have only 10
submissions available, use them wisely. The flag format is
`FortID{<32_hex_characters>}`

[https://fortid-eudai.chals.io/](https://fortid-eudai.chals.io/)
