# FortID CTF 2025

This CTF took place in September 2025, it lasted for 48 hours, and featured 32
challenges in the following categories:
  * [Intro](Intro/README.md)
  * [Crypto](Crypto/README.md)
  * [Misc](Misc/README.md)
  * [Pwn](Pwn/README.md)
  * [Rev](Rev/README.md)
  * [Web](Web/README.md)

Congratulations to the winners:
  * :1st_place_medal: **w4llz** with 28 captured flags, scoring 8546 points.
  * :2nd_place_medal: **ICC UH** with 27 captured flags, scoring 8054 points.
  * :3rd_place_medal: **Information Security PTIT** with 24 captured flags, scoring 6723 points.

The full scoreboard is published on [CTFtime](https://ctftime.org/event/2893).
